# Changelog

All notable changes to this project will be documented in this file.

## 0.1.0 - 2026-08-08

### Added

- Adapter-first player core with typed lifecycle, events, capability detection, and media surfaces.
- HLS, HTTP/WS-FLV, HTTP/WS MPEG-TS, native media, and raw Annex-B H.264/H.265 adapters.
- Injectable WASM decoder contract and WebCodecs Canvas renderer.
- Shared RTSP-to-WebSocket MPEG-TS relay using FFmpeg stream copy.
- Vue 3, React, and Web Component wrappers.
- Vue protocol workbench, local media fixture generator, tests, and bilingual documentation.
